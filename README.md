# Portafolio

Portafolio personal construido con Angular 22, Tailwind CSS 4 y prerender estático.

## Desarrollo

```bash
npm install
npm start        # http://localhost:4200
npm test         # Vitest
npm run build    # sitio estático en dist/portafolio/browser
```
